GSAP Floating & Reveal

단순한 움직임을 넘어 시간의 흐름을 설계하는 라이브러리

소개

프로젝트의 몰입감을 높이기 위해 사용자의 시선을 자연스럽게 유도하는 Floating & Reveal 효과를 구현하고자 했습니다.

CSS Transition의 단순 반복을 넘어 GSAP을 선택한 이유는 수십 개의 애니메이션을 하나의 Timeline으로 통합 관리하는 코드 효율성과 미세한 속성 조절을 통해 움직임을 설계할 수 있는 정교한 제어력 때문입니다.

예제 화면

프로젝트에 사용했던 Floating & Reveal 효과 데모가 준비되어 있습니다.

예제 코드

yoyo & repeat

애니메이션을 무한 반복시키고 역재생하는 yoyo 옵션을 통해 끊김 없이 움직이는 배경을 구현했습니다.

utils.random

고정된 수치가 아닌 범위 내 랜덤 값을 부여하여 각 요소가 서로 다른 궤적과 속도로 움직이는 자연스러운 효과를 완성했습니다.

gsap.timeline

여러 애니메이션을 하나의 timeline으로 묶고 상대적 시점(-=)을 활용하여 각 요소의 등장 흐름을 유기적으로 연결했습니다.

stagger

모든 글자가 한 번에 나타나지 않고 미세한 시차를 두며 순차적으로 드러나는 리듬감 있는 시각적 연출을 더했습니다. 

/*floating 효과*/
gsap.utils.toArray(".circle").forEach((el, i) => {
  gsap.to(el, {
    x: "random(-200, 200)",
    y: "random(-150, 150)",
    scale: "random(0.8, 1.2)",
    duration: "random(4, 7)",
    repeat: -1,
    yoyo: true,
    ease: "sine.inOut",
    delay: i * 0.5,
  });
});

/*reveal 효과*/
const tl = gsap.timeline({
  defaults: {
    y: 0,
    opacity: 1,
    duration: 1,
  },
});

tl.to(".title", {
  ease: "power4.out",
  stagger: 0.1,
})

  .to(
    ".desc",
    {
      ease: "power2.out",
    },
    "-=0.6",
  )

  .to(
    "#replay-btn",
    {
      scale: 1,
      ease: "back.out(2)",
    },
    "-=0.4",
  );

비교 분석

단순한 등장 효과라면 CSS만으로도 충분했을 것입니다. 하지만 프로젝트에서 구현하고자 한 것은 요소 간의 유기적인 시차였습니다. CSS의 delay 방식은 요소가 늘어날수록 유지보수가 어려워지며 전체적인 흐름을 한눈에 파악하기 힘듭니다.

반면 GSAP의 Timeline은 각 동작을 순서대로 쌓고 "-=0.6" 처럼 앞 동작과 겹치는 시간을 직관적으로 조절할 수 있게 해줍니다. 덕분에 코드의 가독성을 지키면서도 사용자가 페이지를 지루하게 느끼지 않도록 설계할 수 있어서 효율적이었습니다.

배경의 Floating 효과에 gsap.utils.random을 활용했습니다. 정해진 경로만 반복하는 애니메이션은 사용자에게 기계적이라는 인상을 주지만 범위 내의 랜덤 값을 부여하면 페이지가 멈춰있지 않고 살아있다는 느낌을 준다고 생각합니다.

여기에 back.out이나 sine.inOut 같은 효과를 조합했는데 다양한 속성들을 직접 적용해 보며 사용자가 기분 좋게 느낄 수 있는 움직임을 찾아가는 과정이 재밌었습니다.

주요 학습 포인트

처음에는 요소에 공통적으로 적용된 transition: all 속성 때문에 GSAP 애니메이션이 부드럽지 않고 끊기듯 작동하는 문제를 겪었습니다.

원인을 파악해 보니 GSAP이 인라인 스타일로 수치를 변경할 때마다 CSS의 transition이 이를 가로채서 다시 계산하려고 시도하며 시간 계산의 충돌이 발생한 것이었습니다. 이를 해결하기 위해 transition 범위를 background-color 등 GSAP이 건드리지 않는 속성으로 한정하거나 애니메이션 대상에서는 CSS transition을 제거하여 해결했습니다.

버튼 등에서 CSS의 :hover 효과와 GSAP의 Reveal 효과가 겹치면서 애니메이션이 끝난 후에도 스타일이 의도치 않게 고정되는 현상이 있었습니다.

이를 해결하기 위해 애니메이션 완료 시점에 clearProps: "all"을 사용하여 GSAP이 부여한 인라인 스타일을 초기화하거나 아예 mouseenter/mouseleave 이벤트를 통해 호버 효과까지 GSAP으로 통합 관리함으로써 일관성 있는 인터랙션을 구현했습니다.
