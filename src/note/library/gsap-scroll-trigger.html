GSAP ScrollTrigger

멈춰있는 페이지에 흐름을 만들고 스크롤에 따라 이야기가 시작되게 하는 기술

소개

ScrollTrigger를 학습하며 이를 실제 프로젝트에 어떻게 사용할지 고민했습니다. 콘텐츠의 등장 시점을 설계하여 사용자에게 더 나은 시각적 경험을 제공하고자 했습니다.

단순히 콘텐츠를 나열하기보다 사용자가 페이지를 내려가는 흐름에 맞춰 적절한 효과가 나타날 때 정보에 더 주의 깊게 집중할 수 있다고 생각했습니다.

예제 화면

프로젝트에 사용했던 ScrollTrigger 효과 데모가 준비되어 있습니다.

예제 코드

trigger

애니메이션 시작을 감지할 기준 요소를 지정하여 특정 컨테이너가 화면에 들어오는 순간을 정확히 포착하도록 구현했습니다.

start

요소와 뷰포트의 기준점을 연결하는 정교한 타이밍 설계를 통해 시선이 머물기 좋은 높이에서 효과를 시작시켰습니다.

toggleActions

스크롤 방향이나 재진입 등 상황별 동작 규칙을 정의하여 일회성 실행이나 반복 여부를 제어하며 완성했습니다.

markers

시작과 종료 지점을 화면에 표시하는 도구를 활용하여 의도한 지점에서 애니메이션이 일어나는지 검증했습니다. 

gsap.registerPlugin(ScrollTrigger);

gsap.utils.toArray(".section-container").forEach((container) => {
  const box = container.querySelector(".reveal-box");
  const text = container.querySelector(".reveal-text");

  const tl = gsap.timeline({
    scrollTrigger: {
      trigger: container,
      start: "top 80%",
      toggleActions: "play none none none",
    },
  });

  tl.from(box, {
    y: 100,
    opacity: 0,
    duration: 1,
    ease: "power4.out",
  })

    .from(
      text,
      {
        y: 40,
        opacity: 0,
        duration: 0.8,
        ease: "back.out(1.7)",
      },
      "-=0.6",
    );
});

비교 분석

CSS의 조절만으로도 등장 효과를 만들 수 있지만 요소가 화면의 어느 지점에서 나타날지 정밀하게 제어하는 데는 한계가 있습니다. ScrollTrigger는 트리거가 되는 기준 요소를 자유롭게 지정하고 애니메이션이 시작되는 타이밍을 설계할 수 있어 사용자의 시선 흐름에 최적화된 연출이 가능했습니다.

markers를 활용해 애니메이션의 시작과 종료 지점을 실시간으로 확인하며 정교하게 작업할 수 있다는 점과 별도의 복잡한 스크립트 없이 toggleActions속성만으로 효과의 반복 실행 여부를 한 줄로 제어 가능한 점이 큰 장점이라고 생각합니다.

주요 학습 포인트

처음에는 단순히 페이지를 위아래로 이동시키는 도구로만 생각하고 ScrollTrigger를 접했습니다. 하지만 응용법을 깊게 파고들면서 pin을 활용한 요소 고정, 가로 스크롤 연출, 그리고 scrub을 이용한 스크롤 속도 동기화 등 커스터마이징의 가능성이 무궁무진하다는 점을 깨달았습니다.

이를 통해 다음 프로젝트에서는 더 복잡하고 사용자의 시선을 확실히 끌어당기는 입체적인 레이아웃을 설계할 수 있다는 기대감을 얻었습니다.
