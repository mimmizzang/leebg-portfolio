Isotope Filtering

카테고리별로 분류하고 유연한 애니메이션으로 시각적 즐거움을 더한 필터링 시스템

소개

많은 콘텐츠 속에서 원하는 정보만 빠르게 추려낼 수 있도록 Isotope 필터링을 적용했습니다. 단순히 요소를 숨기고 보여주는 수준을 넘어 요소들이 스스로 자리를 찾아가는 레이아웃 전환으로 시각적 즐거움과 탐색의 편의성을 동시에 챙겼습니다.

카테고리를 클릭할 때마다 요소들이 촤르륵 정돈되는 애니메이션은 페이지에 생동감을 더해줍니다. 다양한 크기의 콘텐츠를 깔끔하게 배치할 수 있어 완성도 높은 레이아웃을 유지하면서도 사용자가 정보를 탐색하는 과정 자체를 즐길 수 있습니다.

예제 화면

프로젝트에 사용했던 Isotope Filtering 효과 데모가 준비되어 있습니다.

예제 코드

layoutMode

높이가 일정한 카드들을 가로로 차곡차곡 정렬하여 리스트 형태의 콘텐츠를 가장 균형 있게 배치했습니다.

filter

클릭한 카테고리의 요소만 즉각적으로 선별하여 노출함으로써 사용자에게 필요한 정보만 탐색하도록 구현했습니다.

percentPosition

Tailwind의 퍼센트 너비를 Isotope 좌표에 동기화하여 리사이즈 시에도 레이아웃 떨림 없는 반응형을 구현했습니다.

imagesLoaded

이미지 로드 완료 후 레이아웃을 계산하도록 제어하여 로딩 속도에 따른 카드 겹침 현상을 방지했습니다. 

const grid = document.querySelector(".grid-container");

if (grid) {
  imagesLoaded(grid, function () {
    const iso = new Isotope(grid, {
      itemSelector: ".grid-item",
      layoutMode: "fitRows",
      percentPosition: true,
      transitionDuration: "0.4s",
      stagger: 30,
    });

    const filterButtons = document.querySelectorAll(".filter-nav button");

    filterButtons.forEach((button) => {
      button.addEventListener("click", () => {
        filterButtons.forEach((btn) => btn.classList.remove("active-filter"));

        button.classList.add("active-filter");

        const filterValue = button.getAttribute("data-filter");
        iso.arrange({ filter: filterValue });
      });
    });
  });
}

비교 분석

일반적인 CSS 방식으로 필터링을 만들면 display: none같은 속성은 중간 애니메이션 과정을 보여주지 못하고 결과만 보여주기 때문에 버튼을 누르는 순간 카드가 순식간에 사라지고 남은 카드들이 빈자리를 향해 퍽 하고 이동하게 됩니다. Isotope는 각 카드의 위치를 실시간으로 계산해서 옮겨주는 방식을 씁니다. 덕분에 카드가 사라짐과 동시에 나머지 카드들이 자기 자리를 찾아 부드럽게 미끄러지듯 이동합니다. 단순히 기능을 구현하는 것을 넘어 사용자가 필터링을 할 때 부드럽다는 인상을 받게 해줍니다.

filter와 layoutMode같은 핵심 매개변수 설정만으로 복잡한 재배치 로직을 내부에서 자동으로 처리할 수 있습니다. 카드 하나하나의 좌표를 직접 계산할 필요가 없으므로 코드의 양은 줄이면서도 결과물의 퀄리티는 훨씬 높여준다고 생각합니다.

주요 학습 포인트

이미지가 포함된 콘텐츠는 로딩 속도가 느려 Isotope가 높이값을 제대로 계산하지 못하고 카드가 겹치는 문제가 있었습니다. 이를 해결하기 위해 imagesLoaded 라이브러리를 연동하여 모든 이미지가 로드된 시점에 레이아웃을 잡도록 설계해 배치 오류를 해결했습니다.

브라우저 리사이즈 시 픽셀 연산 오차로 인해 하단에 가로 스크롤바가 순간적으로 생겼다 사라지며 레이아웃이 꿀렁이는 현상을 확인했습니다. 이를 해결하기 위해 percentPosition: true 옵션을 적용해 모든 좌표를 비율 단위로 고정했고 해상도 변화에도 스크롤 발생 없이 매끄럽게 반응하는 그리드를 완성했습니다.
